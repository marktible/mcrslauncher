MCRS Launcher 0.2.7 is a native desktop launcher for Horizon, the Rust implementation of Minecraft.

### Changes

- Native mod compilation uses all available CPU cores by default for GitHub imports, updates, and rebuilds across performance, release, and development profiles. An explicit `CARGO_BUILD_JOBS` value still takes precedence.
- Offline mode starts an installed, prepared game without sign-in, update checks, downloads, or mod builds. It supports single-player and offline-mode servers; install and prepare the game online first.
- Automatic Horizon update checks can run at startup and every 15 minutes, 30 minutes, or hour, or be disabled. Preferences persist across launches.
- The Updates page checks for MCRS Launcher releases separately from Horizon. Writable native Linux and macOS installations can verify and replace the launcher executable; Windows and other installations offer a verified download for manual replacement. Flatpak installations offer system software update controls.
- Fixed the generated Flatpak repository publisher's Git index reset.
- Fixed offline-play test assertions for canonical temporary paths on macOS.

### Downloads

Linux Flatpak:

```sh
flatpak install --user ./io.github.marktible.MCRSLauncher.flatpak
flatpak run io.github.marktible.MCRSLauncher
```

The first installation needs the shared Freedesktop SDK runtime, which supplies the compiler and libraries used by native mod builds. Horizon and Minecraft resources download during setup.

Native archives are provided for Linux x86-64, Windows x86-64, and the macOS architecture named in its archive. Extract the matching archive and run `mcrslauncher` (`mcrslauncher.exe` on Windows). `SHA256SUMS` contains checksums for all release packages.

### Verification

Local validation includes 59 passing tests, the explicit compiler-job override regression test, formatting, Clippy with warnings denied, a release build, and a Flatpak bundle smoke-tested in the 26.08 runtime. GitHub publication requires the desktop build/test matrix and Flatpak build to pass.

An eligible Minecraft: Java Edition account is required to install and prepare the game online. This is an unofficial project, not affiliated with Mojang or Microsoft.
