MCRS Launcher 0.2.6 is a native desktop launcher for Horizon, the Rust implementation of Minecraft.

### Fixes

- **Engine downloads survive GitHub gateway errors:** temporary HTTP 502–504, timeout and connection failures are retried. If the normal GitHub release-download URL still fails, the launcher uses GitHub's release-asset API and verifies the same published SHA-256 digest before installing.
- **Play is not blocked by a failed update download:** when the engine or game update cannot be downloaded, Play can continue with the verified, prepared installed build after the normal ownership, checksum, prepared-resource and pending-mod checks. Explicit setup and install requests still fail instead of claiming success.
- Added regression coverage for the download fallback, rejected fallback URLs, and playing from an installed build after an update download failure.

### What's included

- Microsoft Minecraft sign-in, real player heads and PNG skin changes.
- Current Horizon downloads, update checks, and preparation before native mod compilation.
- Import native mods from GitHub and build them with Horizon's managed Rust toolchain.
- Download progress with speed and ETA, cancellation, and retries for temporary network failures.
- A resizable desktop window with compact navigation and access to the game folder and activity log.

### Linux Flatpak

Download `io.github.marktible.MCRSLauncher.flatpak`, then install it with:

```sh
flatpak install --user ./io.github.marktible.MCRSLauncher.flatpak
flatpak run io.github.marktible.MCRSLauncher
```

The first installation also needs the shared Freedesktop SDK runtime, which supplies the compiler and libraries used by native mod builds. Horizon and Minecraft resources download during setup; they are not included in the release assets.

### Other desktop downloads

Native archives are provided for Linux x86-64, Windows x86-64, and the macOS architecture named in its archive. Extract the matching archive and run `mcrslauncher` (`mcrslauncher.exe` on Windows).

`SHA256SUMS` contains the SHA-256 checksums for every downloadable package. The release is published after the desktop build/test matrix and Flatpak build pass. Local validation includes 49 passing tests and a live 29,109,458-byte `launcher@0.2.57` engine download through the fallback path with a matching SHA-256 digest.

An eligible Minecraft: Java Edition account is required. This is an unofficial project, not affiliated with Mojang or Microsoft.
