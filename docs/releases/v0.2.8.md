MCRS Launcher 0.2.8 adds local offline profiles and account switching without requiring Microsoft sign-in to play a prepared game.

### Changes

- Select Guest, a saved offline profile, or a Microsoft account from the menu on Play or in Settings.
- Create offline profiles with names of 3–16 letters, digits, or underscores. Profiles and the selected name persist across launches. Remove offline profiles in Settings without deleting worlds or game files.
- Signed-out Play starts the prepared game as Guest or the selected offline profile without an update lookup or authentication request. The selected offline name is passed directly to the client.
- Keep the launch button accessible above the account controls in compact windows.
- Publish these changes as a numbered release so the signed Flatpak repository can update installations that previously received a newer local build.

### Updating

Once this release is published to the signed Flatpak repository:

```sh
flatpak update io.github.marktible.MCRSLauncher
```

Close and reopen MCRS after updating. Game data and settings are retained.

Native archives are available for Linux x86-64, Windows x86-64, and the macOS architecture named in each archive. `SHA256SUMS` contains checksums for every release package. Flatpak installation and remote setup are described in the repository's Flatpak guide.

### Verification and requirements

Local validation covers 61 passing tests, formatting, Clippy with warnings denied, offline-name validation and persistence, and subprocess dispatch as Guest or a named offline player without authentication. Desktop and Flatpak CI builds must pass before this release is published.

An installed game and prepared Minecraft resources are still required. Microsoft sign-in is optional for local play and required for authenticated servers and account-based resource downloads. Full gameplay and live Microsoft account switching have not been exercised by the automated tests.
