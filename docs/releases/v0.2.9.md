MCRS Launcher 0.2.9 makes first-time setup independent of Microsoft sign-in, an existing Minecraft installation, and other launchers.

### Changes

- **Download & set up Horizon** installs the verified official engine and game, downloads the pinned Minecraft client, server, libraries, and assets directly from Mojang's public distribution servers, and prepares them locally.
- No account, session token, or other launcher's installation is used for these resource downloads. Microsoft sign-in remains optional for authenticated online services.
- Resource manifests, game files, libraries, and assets are verified against their pinned SHA-1 checksums. Downloads use temporary files and atomic replacement; completed valid files are reused on retry. Independent files download concurrently with progress and cancellation.
- Horizon still manages the Java runtime needed for preparation. Game resources and downloads remain in this launcher's application data folder.
- Setup also works when an offline profile was selected first. It is an explicit download request and preserves the saved offline-play preference.
- **Restore engine** continues to repair just the launcher engine. Play reuses prepared resources; setup remains available when resources are missing.

### Updating

```sh
flatpak update io.github.marktible.MCRSLauncher
```

Close and reopen MCRS after updating, then select **Download & set up Horizon**. An internet connection and disk space for the initial downloads and preparation are needed. After setup, play as Guest or an offline profile without signing in. Authenticated servers still require a Microsoft account.

Native archives and the Flatpak bundle are included in this release, with `SHA256SUMS` for verification.

### Verification

65 local tests cover the existing launcher flows plus account-free setup, metadata validation, checksum rejection, cache reuse and repair, atomic writes, and cancellation. A separate live test downloaded the official engine and game into an isolated first-run folder, downloaded and prepared the required resources with no account, and successfully reused them for another preparation run. Full gameplay was not launched by that test. Desktop and Flatpak builds must pass before publication.
