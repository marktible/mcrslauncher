# MCRS Launcher 0.2.11

Closing the launcher window now keeps your running game alive. This also works inside Flatpak: the launcher closes its window and keeps the game worker running until the game exits. **Stop game** still terminates the game explicitly, and closing during preparation or downloads still cancels that work.

Automatic Horizon update checks now default to **At startup only**. Saved update preferences are preserved, and checks before playing remain a separate setting.

The Updates page now has clear, compact cards for MCRS Launcher and Horizon, with installed and available versions, concise status messages, and focused actions. Wide windows show the cards side by side; narrow windows stack them. Release notes and Flatpak terminal commands are expandable, and HTML release bodies are shown as readable text.

The signed Flatpak repository continues to use the project's original trusted signing key.
