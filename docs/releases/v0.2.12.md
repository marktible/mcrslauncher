# MCRS Launcher 0.2.12

- Windows launcher updates now install automatically after choosing **Restart to update**. A helper waits for the launcher to exit, replaces the verified executable, and reopens MCRS. It retains the previous version until the updated executable starts and restores it if starting fails.
- Added **Settings → Launcher updates → Automatically update MCRS Launcher**. Enable it for startup and hourly checks and automatic verified downloads. It defaults to off, works independently of Horizon update settings, and pauses in Offline mode.
- Manual launcher updates remain available. Unwritable installation folders retain the verified download for manual replacement.

Windows users upgrading from 0.2.11 or earlier need to replace the executable manually once to get the new updater.
